# Turnward Compass — Privacy Policy

The published privacy policy for the **Turnward Compass** Android app.

Live at: https://autumnwing.github.io/turnward-privacy/

This repository exists only to host that one page. Google Play requires a
publicly reachable privacy policy URL, with no sign-in, and this is it.

The source of truth lives with the app, at `privacy/index.html` in the app's
own repository. Edit it there and copy the result here, so the policy and the
app it describes cannot drift apart.
